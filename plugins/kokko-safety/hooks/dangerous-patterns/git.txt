# git.txt - Git operations worth a confirmation prompt (ASK tier).
#
# SCOPE: this file is the ASK tier only.
#
# The commands that irrecoverably destroy work -- rebase, reset, checkout
# <ref> -- <path>, restore, stash, clean, force-push, `git add .`, and anything
# that eats the reflog or unreachable objects -- are handled directly in
# pre-tool-destructive-git.sh, which DENIES them (dirty-tree-gated where that is
# the deciding factor). They were removed from this file rather than left to
# double up: a prompt after a denial is noise, and noise is what got this plugin
# switched off in a real settings.json, protecting nothing.
#
# `git push origin main` was also removed -- pre-tool-branch-protection.sh
# already covers protected-branch operations, and asking twice for one action
# trains people to stop reading.
#
# What is left is genuinely ambiguous: reversible with effort, occasionally
# correct, and worth one prompt.
#
# NOTE: patterns here are anchored to a command position by the hook, so they do
# not fire inside string literals. Every pattern must therefore begin with
# `git[[:space:]]`.

# Branch deletion (recoverable via reflog, but rarely intended)
git[[:space:]]+branch[[:space:]]+(-[dD]|--delete)

# Remote branch deletion (not recoverable from your local reflog)
git[[:space:]]+push[[:space:]]+(.*[[:space:]])?--delete
git[[:space:]]+push[[:space:]]+[^[:space:]]+[[:space:]]+:[^[:space:]]

# Tag deletion
git[[:space:]]+tag[[:space:]]+(-d|--delete)
git[[:space:]]+push[[:space:]]+.*[[:space:]]+:refs/tags/

# Interactive rebase on a CLEAN tree (a dirty tree is denied outright).
# Still worth a prompt: it rewrites history that may already be pushed.
git[[:space:]]+rebase[[:space:]]+(-i|--interactive)

# Untracking files -- looks like a delete in the diff and often surprises
git[[:space:]]+rm[[:space:]]+--cached

# Submodule and worktree removal (deletes their working directories)
git[[:space:]]+submodule[[:space:]]+deinit
git[[:space:]]+worktree[[:space:]]+(remove|prune)

# Remote manipulation
git[[:space:]]+remote[[:space:]]+(remove|rm)

# Config manipulation (security-sensitive)
git[[:space:]]+config[[:space:]]+--global[[:space:]]+--unset
git[[:space:]]+config[[:space:]]+--system
